# Project Context: Shajare Telegram Bot (shajare1_bot)

- **OS & Host:** Ubuntu Linux VPS (`root@ubuntu-London-0`)
- **Project Directory:** `/root/shajare1_bot`
- **GitHub Repository:** `https://github.com/sepantasaadat/shajare1_bot.git`
- **Isolation Constraint (CRITICAL):** This VPS also hosts an active website and another Telegram bot for a Psychological Clinic. All operations, packages, and configurations for `shajare1_bot` MUST remain strictly isolated within its own directory and virtual environment (`/root/shajare1_bot/venv`) to prevent any port, package, or process conflicts.

## 2. File Structure & Tech Stack
- **Main Bot Script:** `/root/shajare1_bot/telegram_bot_shajare.py`
- **Database/Data File:** `/root/shajare1_bot/posts.json`
- **Virtual Environment:** `/root/shajare1_bot/venv`
- **Python Dependencies:** 
  - External: `python-telegram-bot` (v20+ asynchronous architecture using `ApplicationBuilder`, `ContextTypes`, `CommandHandler`, `CallbackQueryHandler`, `MessageHandler`, `filters`, `InlineKeyboardButton`, `InlineKeyboardMarkup`, `Update`).
  - Built-in modules used: `json`, `os`, `asyncio`, `random`.
  - Note: No `requirements.txt` currently exists in the repository.

## 3. Security & Environment Variables
- The Telegram Bot Token is **never** hardcoded in `telegram_bot_shajare.py` to keep the public GitHub repository secure.
- In Python, the token is retrieved via:
  `BOT_TOKEN = REDACTED
- The actual token value is injected via the `systemd` service environment configuration on the server.

## 4. Production Deployment (Systemd Service)
- **Service Name:** `shajare_bot.service`
- **Service Path:** `/etc/systemd/system/shajare_bot.service`
- **Current Status:** Enabled on boot and `active (running)`.
- **Service Configuration:**
  [Unit]
  Description=Shajare Telegram Bot Service
  After=network.target

  [Service]
  Type=simple
  User=root
  WorkingDirectory=/root/shajare1_bot
  Environment="BOT_TOKEN=REDACTED_ON_SERVER"
  ExecStart=/root/shajare1_bot/venv/bin/python /root/shajare1_bot/telegram_bot_shajare.py
  Restart=always
  RestartSec=5

  [Install]
  WantedBy=multi-user.target

## 5. Development & Maintenance Workflow Rules
1. **Step-by-Step Preference:** Always guide me step-by-step and tell me exactly which lines/sections of the code to modify rather than sending full rewritten scripts all at once.
2. **Adding Packages:** Always activate the virtual environment first (`source /root/shajare1_bot/venv/bin/activate`) before installing any new pip packages.
3. **Applying Code Changes on Server:** After modifying `telegram_bot_shajare.py` or pulling updates from GitHub (`git pull`), restart the service using:
   `sudo systemctl restart shajare_bot`
4. **Monitoring Logs:** Check live logs and errors using:
   `sudo journalctl -u shajare_bot -f -n 50`
